This release improves DS339 startup after a black or corrupted display and
libusb transfer timeout `-116`.

- Initialize the panel control registers and GPIO before sending pixels.
- Send two complete initial frames before enabling the screen.
- Transfer frames in 64 KiB chunks and identify the failing chunk or
  end-of-frame transfer in error messages. Failed frames are not replayed.
- Include USB troubleshooting documentation in the downloadable archives.

Windows validation: the existing OEM driver was retained; the physical color
bars, 16 consecutive clock updates, repeated initialization, and GUI
**Start / Apply** were verified. Unit tests, formatting, clippy and the Windows
release build passed. Linux hardware operation remains unverified.

The trigger for the reported failure after approximately two months of normal
use remains unknown. The corrected startup sequence restored operation on the
tested device; individual initialization writes were not isolated separately.

On Windows, install the official JONSBO driver/software first and close other
DS339 output programs. `libusb0.dll` is required and is not bundled.
